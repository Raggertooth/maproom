# Changelog

Notable changes to Maproom are documented here.

## 0.1.0 — Initial public project

- Added a local-first browser mind-map editor with outline, canvas, inspector, undo/redo, and autosave.
- Added radial, directional, and organisation-chart layouts.
- Added local JSON persistence, topic notes and status, branch colours, and cross-links.
- Added an MCP stdio server with nine tools for agents to create and manage maps.
- Added OPML, SVG, PNG, and PDF export paths.
- Added documentation for setup, agent integration, architecture, development-diagram patterns, data formats, security, and contributions.
